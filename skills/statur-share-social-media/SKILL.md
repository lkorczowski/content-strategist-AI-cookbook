# Share social media access

Part of STATUR social analytics (https://statur.co/blog/own-your-social-media-analytics/). Before the first weekly review, the person who reads the data needs the numbers. This skill gets the owner there in one sitting, platform by platform, with the least access that does the job.

Platforms rename their menus often. If a step does not match what the user sees, ask for a description or a screenshot and adapt. Never guess a menu path and present it as fact.

## What to ask for

Ask once, then work with what the user gives you.
- The platforms and handles in use, and whether each account is personal, Creator or Business today.
- The email the advisor gave for access (from the engagement brief, if the project has one), and the advisor's password manager share address if TikTok is in scope.
- Whether a Facebook Page and a Meta business portfolio already exist, and who controls them.
- Whether the user wants to keep the current accounts or create new ones, and why.

## Principles

1. Least access: insights and content first. Payment, admin and ad-account rights only when the engagement needs them.
2. No password in plain text, ever. Use delegated access where the platform offers it. Where it does not, use a password manager share, with two-step verification kept on by the owner.
3. The owner keeps ownership. The advisor is invited; nothing is transferred.
4. Creator before Business for founder accounts on Instagram and TikTok: Creator and personal accounts keep the wider music library, which trend formats rely on. Switch to Business only for a reason the user states.

## Steps by platform

### Instagram
1. Professional account, type Creator (Settings, Account type and tools). A personal account must be switched first.
2. Connect it to a Facebook Page. Create a Page if there is none.
3. Add the Page and the Instagram account to a Meta business portfolio (business.facebook.com).
4. In the portfolio settings, Users, People, Invite: the advisor's email, Partial access, tick the Page and the Instagram account, with Content and Insights. Add Messages only if the advisor will answer DMs.
5. For an agency with its own portfolio: Partners, give a partner access to your assets, using the agency's Business ID.

### Facebook Page
Same portfolio, same invite. Content and Insights are enough for a strategist.

### TikTok
1. Keep a founder account personal (creator). A Business account is for brands that need TikTok's commercial tools.
2. Personal accounts have no delegated access to analytics. Share the login through a password manager:
   - LastPass: share the item with the advisor's LastPass email.
   - Apple Passwords: create a shared group with the advisor's Apple Account, add the item.
   - Any other manager with item sharing works the same way.
3. Keep two-step verification on. The owner sends the code the first time the advisor signs in.
4. Business accounts can be added to TikTok Business Center and shared with a partner. Check in Business Center which permissions cover what the advisor needs before choosing this route.

### YouTube
YouTube Studio, Settings, Permissions, Invite: the advisor's email, role Viewer for analytics. Editor only if the advisor will upload or edit.

### LinkedIn
A personal profile cannot be shared. Export or screenshot the post analytics for each weekly review. A company page can add the advisor as a page admin with the most limited role that shows analytics.

## Output

```
ACCESS STATUS · <account owner> · <date>
Advisor access email: <email>
| Platform | Handle | Account type | Method | Status (done / to do / blocked by whom) |
Open items:
Next step:
```

Then draft a short email to the advisor with the table, so they can accept the invitations. With an email connector, create a draft; without one, show the text to copy. Never send it.

## Rules

- Drafts only. Never send, post, publish, pay or delete anything for the user.
- Never ask for, store or repeat a password, a token, a recovery code or a card number. The user signs in and clicks.
- No promised views, followers or results.
- No invented menu paths, numbers or platform rules: when unsure, say so and ask what the user sees.
- Respect each platform's terms. A password manager share is the owner's choice and stays under the owner's control; remove it at the end of the engagement.
