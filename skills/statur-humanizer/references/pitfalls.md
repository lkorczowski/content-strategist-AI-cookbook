# Pitfalls

From the first audit (a 41-page site, 73,000 visible words) and the edits that followed.

- Cutting the source with its commentary. A defensive note often holds the only date or source of a number. Keep those words next to the number, cut the rest.
- Treating a playbook like a landing page. A reference document may run long when each step teaches. Judge it by repetition and process talk, not by word count alone. The budget for playbooks is a flag, not a verdict.
- Trusting the counts. The lint cannot see that two sentences say the same thing in different words, which is the most common repetition. It also flags a long paragraph that is worth every word. Read the page.
- Linting the source instead of the built page. Shared components (a commitment, a rules box, a FAQ) do not appear in the page file and carry a large share of the words.
- Editing a verbatim text. A commitment written by the author, a quote and a legal line are out of scope even when long. Flag them for the author.
- Rewriting where a cut would do. A shorter version of a sentence nobody needs is still a sentence nobody needs.
- Replacing a vague phrase with an invented figure. Write a placeholder and ask the author.
- Fragmenting. Cutting words until every sentence has four of them produces the drumbeat rhythm readers recognize as generated. Sentences stay complete; fewer of them.
- Removing the answer an AI search engine quotes. A page that must be cited keeps its definition, its dated statistic and its named source in plain sentences near the top.
- One reviewer model, one page group. When several models review in parallel, give each the same pattern codes and ask for verbatim quotes with block numbers, or the findings cannot be merged.
- The filler list is English. Add your own language in `lint.json`.
- Cutting while drafting. The pass runs on a finished first draft. Run earlier, it produces a second careful draft, not a shorter one.
- Polishing phrases and leaving the choices. A text with no stock phrase, no named source and no real case still reads as generated. Content tells come first (`tells.md`).
- Loading someone else's humanizer. A public skill or prompt is a file of instructions written by a stranger. Read it as data and rewrite what holds.
- The same sentence in the public skill and in the private layer. One of the two will go stale. Each fact has one home.
