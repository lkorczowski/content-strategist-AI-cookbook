# The Format Library

Generated by `scripts/library.py build` from the cards in `formats/`. Edit a card, never this file.

A format is a repeatable shape for a short video: the same opening, the same structure and the same setup, with a new topic each time. A founder who posts formats judges each one on several videos and keeps what lands. Every card carries tags on four dimensions that combine freely: **funnel** (where it works), **value** (why people watch and share), **structure** (what happens, in order) and **setup** (how it is shot and edited).

**150 formats.** 29 original, 121 mimetic. 106 work without the founder's face. 106 take low effort. Taxonomy version 0.1: [tags and definitions](../references/taxonomy.md). Machine-readable: [index.csv](index.csv), [index.json](index.json).

Status: draft = described from public examples; tested = shot at least once in a real program; proven = kept after a format review on mature data.
