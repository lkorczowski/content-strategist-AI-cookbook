# Codex diagrams

A diagram in this style reads as drawn by a person in a notebook, so it escapes the generic AI look (near-black panels, one bright accent, mono labels, perfect geometry). The method comes from the drawings of Leonardo da Vinci's notebooks: brown ink, lines that tremble, a soft shadow that makes each object float on the paper, short hatching along the contour on the side away from the light, and notes written around the figure.

## Intake (ask once, then use the defaults)

1. What is the one idea the figure must carry? One figure, one idea.
2. Which element is the thing to remember? It gets the accent color, and only it.
3. Where will it live: a page with its own paper background (default, transparent SVG), a standalone image or video plate (`--paper --embed-fonts`), a dark video frame (pass a light ink in `--style`).
4. Brand tokens: ink, accent, highlighter, shadow tint, handwriting and serif fonts. Read them from the company context file (kb/01_BRAND.md or .agents/product-marketing.md); otherwise the defaults below apply.

## Default path

```
cd skills/statur-codex-diagram && npm i          # roughjs (MIT) + two OFL fonts for embedding
node scripts/render.mjs examples/handbook-figures.mjs out/            # every example figure + out/index.html contact sheet
node scripts/render.mjs my-figures.mjs out/ --seed 4 --embed-fonts    # your own spec, another "take" of the hand
node scripts/render.mjs --help
```

A spec is a small module: `export const figures = { name: (codex, o) => sketch }`. Copy one figure of `examples/handbook-figures.mjs`, change its shapes and labels, render, look at the contact sheet, adjust. The same seed always gives the same drawing; another seed gives another take with the same composition.

The engine (`scripts/codex.mjs`) has no DOM dependency: the same calls run in Node at build time (static SVG in a site) and in a browser page.

## The vocabulary

| Call | What it draws | Notes |
|---|---|---|
| `circle, ellipse, rect, polygon, path(d)` | closed shapes | options `shadow` (on by default), `hatch` (contour hatching), `stipple` (number of dots), `fill: 'hachure' or 'solid'`, `accent`, `dash` |
| `line, curve(points), polyline(points), arrow` | strokes | `shadow: true` gives a stroke its diffuse shadow |
| `stipple(test, bbox, n, {density})` | dotwork inside any region | `shade(bbox)` returns a density that darkens away from the light |
| `hatchContour(polygon)` | short strokes on the shadow side of a contour | 45 degrees by default, the left-handed hatching of the codex |
| `rays(cx, cy, r1, r2, n)` | radiating hatch around an object | the halo of strokes around a machine drawing |
| `ripples(cx, cy, n, step)` | concentric waves | signal, spread, influence |
| `fluo(x1, y1, x2, y2, width)` | a highlighter stroke under the drawing | multiplied on the paper |
| `label(x, y, text, {accent, font, anchor})` | handwritten note (default) or serif | hand labels are scaled up (`handScale`) and thickened for legibility |
| `note(x, y, text)` | mirror-written note, faded | texture only, never information |
| `medallion(sketch, cx, cy, R, level)` | a profile on a coin, stippled from empty (0) to full (5) | scales, levels, reputation |

## Rules of the style (graded)

- One accent element per figure: the thing to remember (convention, kb design rule).
- Every object gets its diffuse shadow: two blurred copies of its silhouette in the shadow tint, near (blur 5, offset 2,3, opacity about .26) and far (blur 16, offset 4,7, opacity about .10). Observed in the notebooks (practitioner reading, Louis 2026-11-13); values tuned by eye on paper #ECE9E1.
- Light comes from the top left; hatching and darker stipple fall bottom right (convention of the codex drawings).
- Labels are handwritten, short, in the reader's language, placed outside the shapes with a leader line when space is tight.
- Shading is dots or hatching, never a gradient. No drop shadow with a hard edge, no glow.
- Numbers on a figure come from the page and carry their source on the page; illustrative curves say so in the caption.

## Update this skill

Add a primitive in `scripts/codex.mjs` (it must return `this` and push paths through `push` or a layer), add an example figure that uses it, render the examples, compare the contact sheet with the previous one, bump `metadata.version`, add a CHANGELOG line. Revisit the shadow values when the paper color of the brand changes.
