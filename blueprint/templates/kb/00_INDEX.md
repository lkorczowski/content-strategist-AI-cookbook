A chat is never a source of truth. A decision taken in a chat is written in the file above before the chat ends.

## 2. Update rules
- Write in the source of truth, never in a copy.
- Replace outdated documents: move them to archive/<date>-<subject>/.
- Keep the knowledge base short enough to read at the start of a session.
- Versions: MAJOR.SIGNIFICANT in the title, date at the top.
